# The Wire · live week cards

`scripts/wire-live.js` is appended by `scripts/prepare-site.mjs` as the last Wire layer (before the layout guard), with `styles/wire-live.css`.

Cards: `wireLiveCards` is replaced. The lead "Week N · Live" card is centered, with a high-score chip (portrait, manager, score), a games-started chip and one row per matchup: portrait and name each side, live scores (green for the leader), and a small bar with each side's live win chance. Every row carries `data-wire-matchup`, so tapping it opens that matchup in League HQ through the existing handler. Each "Live Matchup" card shows both portraits (profile triggers), the actual score large, the live ESPN projection (`hjAdjustedEspnProjection`, falling back to the schedule projection) and players left under it, a navy/brass win-chance bar with percentages, a "leads by X · Y% to win" line, the top scorers when the box score has loaded, and an "Open in League HQ" button. Win chance compares the two live projected finals with an uncertainty that shrinks as the points still to come shrink (normal approximation, spread 2.3 × √(remaining projected points + 4 per unfinished starter)); it only goes to 100/0 when every starter on both sides is in a finished NFL game. "Players left" also counts starters whose game is still in progress, not only those yet to kick off (the old 100% readings came from treating an in-progress game as done).

Carousel stability: every card gets a unique label and `data-wire-key` (all Live Matchup cards used to share the label "Live Matchup", so each redraw looked for the card you were on, found the first Live Matchup card and jumped there); `wireRender` remembers the centered card's key and puts you back on it after the redraw. The headline and section chips skip identical rewrites so their rail keeps its scroll position. the `#wire-scroll` element's `innerHTML` setter patches cards in place through `hjPatchLiveContent` (no image reload, scroll position kept) instead of replacing them; `wireScrollTo` scrolls instantly for 400 ms around any `wireRender` so a score refresh never animates the carousel, while taps, arrows and keys still scroll smoothly; `wireUpdateDots` only moves the chip rail's own `scrollLeft` (the old `scrollIntoView` could drag the page vertically on mobile Safari).
